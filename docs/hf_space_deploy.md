# Deploy the GridGreen demo (app.py) to Hugging Face Spaces

About 15 minutes. Free tier (CPU basic) is enough. Per CLAUDE.md §4, if this isn't
working within 1 hour, skip it: the demo video runs locally and that is fine.

## 0. Before you start (on your laptop, in the repo)

```bash
make data && make train && make eval     # makes test.csv, model.joblib, metrics.json
make app                                 # check http://127.0.0.1:7860 shows both lines
.venv/bin/python -c "import gradio; print(gradio.__version__)"   # note it (6.32.0 on Nov 14)
```

`data/processed/test.csv` is **gitignored** in our main repo (it's regenerated by
`make data`), so it is NOT on GitHub. You must upload it to the Space by hand (step 3).

## 1. Create the Space

1. Sign in at https://huggingface.co → **New** → **Space**.
2. Name: `gridgreen`. License: MIT (or whatever the team picks). **SDK: Gradio**. Hardware:
   **CPU basic (free)**. Visibility: **Public** (judges must open it without logging in).
3. Click **Create Space**.

## 2. The Space's README.md (config card)

The Space is a separate repo from our GitHub repo. Its `README.md` is only a config card,
**not** our project write-up. Replace the generated one with:

```yaml
---
title: GridGreen
emoji: 🌱
colorFrom: green
colorTo: gray
sdk: gradio
sdk_version: 6.32.0      # must match the local version from step 0
python_version: "3.12"
app_file: app.py
pinned: false
---

GridGreen: next-24-hour grid carbon intensity forecast for PJM (Chicago).
Code, data sources and write-up: https://github.com/Santosh-Krishna-Reddy/Veritas-AI-Project
```

Why pin `sdk_version`: app.py uses Gradio 6 APIs (`demo.launch(theme=...)`,
`gr.LinePlot(color=..., sort=...)`). An older Gradio would crash at startup.

## 3. Files to push (exact list, keep the folder structure)

| Path in the Space | Why it's needed |
|---|---|
| `README.md` | the config card from step 2 |
| `app.py` | the Gradio app; Spaces runs `python app.py` |
| `requirements.txt` | pandas, numpy, scikit-learn, joblib (Gradio itself comes from `sdk_version`) |
| `ml/__init__.py` | makes `ml` importable |
| `ml/config.py` | region, paths, column names |
| `ml/features.py` | builds the lag/calendar/weather features |
| `ml/baseline.py` | persistence line on the chart |
| `ml/recommend.py` | cleanest hours + kg CO₂ saved |
| `ml/train.py` | app.py imports `MODEL_PATH` from it |
| `ml/artifacts/model.joblib` | **the trained model** (~1.1 MB) |
| `data/processed/test.csv` | **the last 192 hours the forecast starts from** (~0.5 MB, gitignored in our repo) |
| `results/metrics.json` | the live MAE / overlap caption under the chart |

Not needed: `ml/fetch.py`, `ml/data.py`, `ml/evaluate.py`, `ml/failures.py`, `api/`,
`tests/`, `data/raw/`, `data/processed/train.csv` (test.csv has more than 192 rows, so the app
never falls back to train.csv), `ml/artifacts/model_lags_only.joblib`.

Check the list is still right (prints every `ml` module app.py loads):

```bash
.venv/bin/python -c "import sys, app; print(sorted(m for m in sys.modules if m.startswith('ml')))"
```

### Option A: browser upload (no extra tools)

Space page → **Files** → **Add file** → **Upload files**. Drag the files in. For files in
folders, either drag the whole folder or type the folder into the file name
(e.g. `ml/artifacts/model.joblib`). Commit message: `deploy: GridGreen demo`.

### Option B: git

```bash
git clone https://huggingface.co/spaces/<your-hf-username>/gridgreen ../gridgreen-space
cd ../gridgreen-space
mkdir -p ml/artifacts data/processed results
cp ../Veritas-AI-Project/{app.py,requirements.txt} .
cp ../Veritas-AI-Project/ml/{__init__,config,features,baseline,recommend,train}.py ml/
cp ../Veritas-AI-Project/ml/artifacts/model.joblib ml/artifacts/
cp ../Veritas-AI-Project/data/processed/test.csv data/processed/
cp ../Veritas-AI-Project/results/metrics.json results/
# edit README.md as in step 2
git lfs install && git lfs track "*.joblib"   # HF rejects plain-git binary files
git add .gitattributes . && git commit -m "deploy: GridGreen demo" && git push
```

Log in for the push with a Hugging Face **access token** (Settings → Access Tokens,
"write" role) as the password. Never commit the token.

## 4. Check it

1. The Space page shows **Building**, then **Running** (2–5 min). If it shows
   **Runtime error**, open **Logs**. Common causes:
   - `FileNotFoundError: No processed data found`: `data/processed/test.csv` is missing.
   - `No model at ml/artifacts/model.joblib`: the model wasn't uploaded, or it's an LFS pointer.
   - `TypeError ... launch() got an unexpected keyword argument 'theme'`: `sdk_version` is below 6.
   - scikit-learn "InconsistentVersionWarning" / unpickling error: pin `scikit-learn==<local
     version>` in the Space's requirements.txt
     (`.venv/bin/python -c "import sklearn; print(sklearn.__version__)"`).
2. Open the Space in a private/incognito window: two lines on the chart, caption with MAE
   numbers, slider changes the kg saved.
3. Paste the URL (`https://huggingface.co/spaces/<user>/gridgreen`) into
   `coordination/status.md` → `HF_SPACE_URL`.
